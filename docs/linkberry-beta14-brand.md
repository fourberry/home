## 요약

Windows beta.14 기준의 기능 소개·화면·FAQ 갱신입니다. 사용자가 미리보기에서 기능 소개·화면·FAQ의 정상 표시를 확인한 뒤 이번 변경의 커밋과 공개 브랜드 사이트 반영을 승인했습니다. 기존 다운로드와 자동 업데이트는 유지합니다.

## 변경 범위

- 제품 정본 `data/linkberry.ts`: SSH·SFTP 소개를 유지하고 Markdown·목차·편집/미리보기·이미지·Mermaid·메모 연결·PDF·백업/복원 설명을 추가했습니다. 기능 8개와 FAQ 12개이며 홈 도구 요약도 같은 데이터를 사용합니다.
- 화면: 기존 메모 보드 사진을 beta.14로 교체하고 메모 편집, 이미지 편집, 다이어그램·메모 연결 사진 3개를 추가했습니다. 터미널·파일·원격 편집·명령어의 기존 사진 4개는 보존했습니다. 갤러리는 8개 항목에 맞춰 PC 4열, 모바일 2열로 배치합니다.
- 페이지: 도입 문구·기능/FAQ 제목·검색 설명을 갱신하고 안내 4개를 PC 2열로 정렬했습니다. 기존 다운로드 폼과 베타 제한·Mac 시험본 안내를 유지합니다.
- 메모 백업에서 접속 설정·인증 정보·초안 제외, 연결 대상 메모 자동 포함 안 됨, 내부 메모 휴지통/최근 수정 이력 20개 범위를 FAQ에 명시했습니다.

## 공개 문구의 근거와 촬영

제품 동작의 근거는 BerryLinker 저장소의 beta.14 공개 후보, `NOTE_LIBRARY.md`, `NOTE_RETENTION.md`, `NOTE_LINKS.md`와 사용자 인수 결과입니다. 촬영에는 공개 후보와 제품 파일이 같은 beta.14 분리 시험 소스를 사용했습니다. 실제 UI·저장·미리보기·Mermaid 렌더링을 사용하며 화면 요소를 합성하거나 제품 코드를 고치지 않았습니다. 예시 메모 3개와 별도로 만든 서비스 점검 현황 이미지만 사용했습니다. 사용자 메모·연결 폴더·접속 정보·설치 앱은 촬영에 사용하지 않았고 업데이트 기능은 연결하지 않았습니다.

사진은 3198×1794 PNG이며 메모 보드·편집·이미지 편집·다이어그램 화면입니다. 이미지 편집 사진은 도구와 대체 텍스트·설명·표시 너비를 보여주는 실제 창입니다. 기존 SSH 화면까지 모두 beta.14에서 다시 촬영했다고 표현하지 않습니다. 신규 외부 의존성·새 기능·새 경로는 추가하지 않았습니다. 기존 갤러리를 확장했고, 항목 수가 짝수가 되어 필요 없어진 마지막 버튼 전체 폭 CSS만 제거했습니다.

## 검증 결과

- 최종 `npm run generate` 성공: 프리렌더 43개 경로. 기존 Nuxt cache-driver 해석 경고는 남아 있으며 생성 실패는 없었습니다.
- 기존 배포 `verifySite` 재사용: 색인 대상 15개 URL의 고유 제목·h1 1개·설명·canonical·색인 설정 및 FAQ 본문/JSON-LD 일치 확인.
- 변경 페이지: 기능 8개·갤러리 8개·FAQ 12개 중복 없음, 설명·이미지 링크·대체 텍스트가 정적 HTML에 존재. FAQ JSON-LD 12개 확인.
- 다운로드: beta.14 EXE·beta.yml 및 Windows 과거 다운로드 12개 무결성 검증. Mac 파일 4개의 크기·해시 확인. Windows/Mac 릴리스 정본 파일의 Git 변경 없음.
- 공개 HTML·JS/CSS 번들에 내부 PC 경로·시험 암호·서버 비밀 설정 미노출 확인.
- 실제 브라우저: 브랜드 페이지 PC 1280×720·1440×1080, 모바일 390×844 가로 넘침 없음. 8개 화면 모두 이미지 정상 로드, 선택·Home/End/방향키 순환, 이미지 확대·Tab 포커스·Esc 닫기·원래 링크로 포커스 복귀 확인. 모바일 확대 이미지 내부 가로 스크롤 확인.
- 공통 데이터가 반영되는 홈 도구 영역: PC·390px에서 기능 태그 8개와 가로 넘침 없음 확인. 마지막 검사 브라우저 오류/경고 0건.
- JS 비활성은 정적 HTML과 기존 표시 방어 코드를 확인했으며, 실제 브라우저의 JS 차단 시험은 하지 않았습니다. 모션 감소는 기존 `prefers-reduced-motion` 규칙 보존과 자동 전환·신규 애니메이션 없음으로 코드 확인했습니다. 실기 휴대전화·다른 브라우저·스크린리더 음성 출력·실제 검색 색인/AI 인용 성과는 미검증입니다.
