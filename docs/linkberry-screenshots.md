## 요약

LinkBerry 브랜드 페이지 `/tools/linkberry/`에 실제 앱의 데모 화면 5장과 기능별 설명을 추가합니다. 2026-10-21 사용자는 대표 화면·문구의 반영과 추가 네 화면 촬영, 슬라이드 구성 및 배포 전 미리보기를 승인했습니다. 미리보기 검토 후 같은 날 사용자가 검증한 9개 파일의 커밋·Push·배포와 공개 페이지 확인을 추가 승인했습니다.

## 화면과 근거

| 화면 | 실제 촬영 내용 | 확인 범위 |
|---|---|---|
| 분할 터미널 | 파일 탐색기와 서비스 상태·로그 터미널 두 개 | 앞서 사용자가 확인한 대표 PNG 원본 그대로 사용 |
| 파일 전송 | 파일 목록, 다운로드 메뉴, 업로드 완료 상태 | 격리된 SSH/SFTP 서버로 예제 파일 업로드 후 바이트 일치 확인 |
| 원격 편집 | nginx.conf 편집기와 저장하지 않은 변경 상태 | 실제 SFTP 읽기·편집·저장 후 서버 파일 내용 확인 |
| 명령어 사전 | 로그 검색과 docker logs 설명·예제 | 앱의 기존 명령어 사전 UI 사용 |
| 작업 메모 | 서버별 메모 6개, 색상·태그와 보드 배치 | 앱 저장소 API로 생성한 가상의 배포·경로·작업 기록 |

촬영 기준은 LinkBerry `main/d8266a199512a9f234858127d778b100a960cb60`, 버전 `0.1.1-beta.10`의 변경 없는 제품 소스입니다. 설치본이 아니라 동일 UI의 개발 실행이며 상단에도 개발 실행으로 표시됩니다. 대표 촬영 도구를 재사용하고 기존 `test/fixture.cjs`의 격리된 로컬 SSH/SFTP 연결로 데이터를 전달했습니다. 터미널의 서비스 상태·로그는 합성 예시이며 실제 운영 서버 점검 결과가 아닙니다. 실제 고객·운영 서버·계정·인증 정보는 사용하지 않았습니다.

PNG는 3200×1800 해상도이며 5장 합계 약 1.47 MiB입니다. 승인된 대표 이미지의 해시를 보존합니다. 페이지에서는 원본 비율을 유지하고 확대 화면은 작은 화면에서도 가로·세로로 스크롤할 수 있습니다.

## 구현 범위와 검색 영향

- 제품 설명·이미지 경로·대체 텍스트는 기존 `data/linkberry.ts`에 추가합니다. 기존 브랜드 페이지·색상·레이아웃·SEO·FAQ·다운로드 정보는 재사용합니다.
- `components/brand/LinkberryGallery.vue`는 기능 선택, 이전·다음 전환, 확대를 묶은 페이지 전용 컴포넌트입니다. 기존 `FbZoomImage`에는 슬라이드 전환, 작은 화면에서의 원본 탐색, 모달 키보드 포커스 처리가 없어 네이티브 `dialog`를 사용하는 전용 구성으로 추가했습니다. 공통 확대 컴포넌트는 변경하지 않습니다.
- 자동 전환·새 애니메이션·새 의존성은 추가하지 않습니다. 키보드 방향키·Home·End로 기능을 선택하고 확대 화면은 Escape·닫기 버튼으로 닫습니다.
- JavaScript 실행 전 정적 HTML에 다섯 기능의 설명과 이미지 링크를 모두 포함합니다. 실행 후에만 한 장씩 표시합니다. 이는 GEO·AEO 관점에서 본문을 이미지나 클릭 후 로딩에만 의존하지 않도록 하기 위한 구성입니다.
- URL·canonical·메타·FAQ 구조화 데이터·사이트맵 대상 수는 변경하지 않습니다. 새 성능·보안·출시 완료 주장은 추가하지 않습니다.

## 검증과 현행 상태

촬영·데모 업로드·편집 저장 검증 완료. `npm.cmd run generate`가 성공했고 정적 산출물 검사 6개가 통과했습니다. 페이지 h1 1개·제목·설명·canonical·색인 설정, 다섯 기능의 정적 HTML·이미지, FAQ 본문/JSON-LD 일치, 15개 사이트맵 URL, 다운로드 메타·필수 확인란, 클라이언트 번들의 내부 경로·시험 암호 미노출과 대표 이미지 해시 보존을 확인했습니다.

실제 브라우저에서 PC 1440×1080과 모바일 390×844의 가로 넘침 없음, 기능 선택·이전/다음 순환, 방향키·Home·End, 확대 다이얼로그의 초기 포커스·Tab·Escape·닫기 후 복귀, 모바일 확대 이미지의 가로 스크롤을 확인했습니다. 5개 이미지의 원본 크기와 로드 완료를 확인했고 이 검증 중 브라우저 오류·경고는 0건입니다. 로컬 미리보기는 `http://127.0.0.1:4000/tools/linkberry/#screens`입니다.

JavaScript 비활성 대응은 생성 HTML과 코드로 확인했으며 브라우저에서 JavaScript 자체를 끄는 시험은 하지 않았습니다. 모션 감소는 새 애니메이션·자동 전환 없음과 기존 전역 CSS의 동작 감소 규칙 보존을 코드로 확인했습니다. 실기 휴대전화·다른 브라우저·스크린리더 음성 출력은 미검증입니다. 기존 Baseline/Browserslist 데이터 경고와 Nuxt cache-driver 해석 경고가 있었으나 정적 생성은 종료 코드 0으로 완료했습니다. 설치 파일·업데이트 채널은 변경하지 않았으며 이번 미리보기 작업에서 설치 파일 다운로드·배포 검사를 다시 수행하지 않았습니다.

최종 읽기 전용 검토에서 추가 실행 가능한 지적은 없었습니다. 이 저장소에는 별도의 `qualityGate.command`·테스트 스크립트·회사 기준 pin이 없으므로 프로젝트 지침의 정적 생성 및 UI·검색 영향 검증을 적용했으며 회사 계약 전체 검증으로 표현하지 않습니다. 공개 배포 전 사용자 검토와 배포 승인이 완료됐습니다. 배포 실행 결과와 공개 페이지 검증은 해당 커밋의 GitHub Actions 기록 및 작업 완료 보고에서 확인합니다.

홈페이지 정본은 `C:\project\homepage`, `main/281b302ef2736f0a701a7beb69842a495816ed19`입니다. 분리된 미리보기 Worktree는 `C:\project\fourberry\linkberry\.test-artifacts\homepage-brand-slides`의 같은 HEAD이며 detached 상태입니다. 최종 확인한 9개 파일(기존 페이지·데이터 2개, 전용 컴포넌트·문서 2개, 이미지 5개)을 정본 main의 미커밋 변경으로 복사하고 파일별 해시를 대조합니다. 미리보기 준비 중 생성했던 미사용 브랜치는 정리했고 커밋은 만들지 않았습니다. 원본 LinkBerry의 기존 미커밋 변경과 사용자 설치본·설정은 보존합니다. 파일 삭제·기존 코드 제거·의존성 변경·개인/회사/프로젝트 AI 규칙 변경은 없습니다.


## BerryLinker 이름 변경 — 2026-10-21

제품명을 BerryLinker(베리링커)로 확정하면서 기존 촬영 도구와 격리된 로컬 SSH/SFTP 데모를 재사용해 다섯 화면을 다시 촬영했습니다. 이전 대표 이미지 보존 기록은 위의 과거 배포에 해당하며 이번 이름 변경 승인 범위에서 새 화면으로 교체합니다. 화면은 현재 개발 소스의 실제 UI이며 공개 Windows 설치본은 아직 이전 이름입니다. URL·설정 경로·기존 설치 파일의 이름과 해시는 보존합니다. 새 이름의 화면과 Mac 다운로드 영역을 정적 생성 및 PC·390px 브라우저에서 확인했습니다. 공개 배포 결과는 이 변경을 포함한 GitHub Actions 기록과 작업 완료 보고를 따릅니다.
