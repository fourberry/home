## 용량 측정

같은 다운로드 파일을 포함한 로컬 정적 생성 결과를 비교했습니다. 압축 전 수치이며 Actions의 업로드 압축 산출물 크기와는 다릅니다.

| 항목 | 변경 전 | 변경 후 |
|---|---:|---:|
| `.output/public` 전체 | 1,168,869,340 bytes | 1,066,703,257 bytes |
| 이미지 | 70,982,719 bytes | 28,207,220 bytes |
| 빌드에 포함된 폰트 | 65,014,776 bytes | 5,627,236 bytes |

전체 감소량은 102,166,083 bytes(약 102.2MB, 8.74%)입니다. 삭제한 폰트 원본은 77,979,900 bytes이며, 이전부터 빌드에 포함되지 않았던 파일도 있어 배포 감소량과 다릅니다.

1GiB(1,073,741,824 bytes) 대비 여유는 약 7.0MB입니다. 기존 설치 파일 9개가 약 1.03GB를 차지하므로 향후 이미지가 늘면 다시 경고가 발생할 수 있습니다. 다운로드 주소 이전·프록시 도입은 이번 변경에 포함하지 않았습니다.

## 검증

- 실제 배포와 같은 문의 엔드포인트를 지정한 `npm run generate` 통과. 기존 Nuxt cache-driver 등 환경 경고는 유지됩니다.
- 변경 전후 18개 HTML의 본문·h1 개수·메타·대표 URL·링크·JSON-LD 비교 일치. 색인 대상 15개 URL의 h1 1개·설명·대표 URL 유지.
- HTML의 자산 참조 86종과 생성 CSS의 파일 참조를 확인했으며 누락 없음. 삭제 자산이 생성 결과에서 참조되지 않는지 확인.
- 기존 EXE 9개와 `beta.yml`의 크기·SHA-256이 변경 전과 동일. `node scripts/prepare-linkberry-download.mjs`로 기존·최신 Windows 및 Mac 배포 파일 검증 통과.
- 정적 배포 폴더를 로컬 4000번 포트에서 직접 제공해 홈·코코넛·베리링커의 PC 및 390×844 모바일 표시 확인. 깨진 로드 이미지·문서 가로 넘침 없음.
- 다운로드 폼의 기존 Windows·Mac GitHub Releases 주소 및 필수 확인란 유지. Windows 확인란 미선택 시 유효하지 않음, 선택 후 유효함을 실제 브라우저에서 확인. 앱 설치·운영 PC 업그레이드는 실행하지 않음.
- GEO·AEO: 공개 본문·FAQ·구조화 데이터·검색 메타·라우팅을 변경하지 않았고, 생성 결과 비교로 유지 확인.
- 최종 읽기 전용 검토에서 새 실행 가능한 지적 없음. 새 의존성·AI 지침 변경 없음.
